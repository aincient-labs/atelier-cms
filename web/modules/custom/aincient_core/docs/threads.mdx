## Start a new thread for a new task

Each new task deserves a **new thread** — a clean context the assistant can focus on. When you're helping Fernway Botanical Studio, you might keep the homepage rewrite in one thread and a new care-guide page in another.

The thread sidebar lists your live conversations, date-grouped into **Today**, **This week**, and **Earlier**.

A thread about a page shows that page's state beside its name — **Draft**, **In review**, or **Live** — in the thread's own language, so you can pick the right conversation without opening it. Hover the marker for the full detail, such as *Draft · published copy live* when a newer draft sits on top of the live page.

## Manage a thread

Every thread has a **⋯** menu. From it you can:

- **Rename** the thread — though threads auto-name themselves from what you're working on.
- **Archive** a thread to tuck it out of the list.
- **Delete** a thread you no longer need.
- **Wrap up** or **reopen** a thread manually.

## Wrapped-up conversations

When you publish a brand-new page, its conversation is **wrapped up** — marked **Done** and made read-only. That keeps a thread whose work is already live from running on. Start a new thread for the next change.

<Tip>
Publishing a new page finishes that thread on purpose. If you want to keep iterating on the same page, start a fresh thread — its live URL stays exactly where it is.
</Tip>

## Choosing an assistant

On rooms that offer more than one assistant, an **assistant picker** at the top of the chat chooses which assistant a new conversation uses.

## Dictate instead of typing

Press the **mic** button to dictate your message using your browser's voice-to-text, then send it like any other message.
