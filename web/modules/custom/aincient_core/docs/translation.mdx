## Add a language

First, add the language you want to publish in.

<Steps>
  <Step title="Open the System back-office">
    Go to **Languages** in the [System back-office](/system).
  </Step>
  <Step title="Add your second language">
    For Fernway Botanical Studio, that might be German alongside English. Once added, it becomes available to translate into.
  </Step>
</Steps>

## Translate a page

With a second language available, open a page and translate it into that language. Atelier offers two modes:

- **Symmetric translation** shares the source page's layout, so only the words change. The German page mirrors the English page's structure — you just swap the text.
- **Asymmetric translation** gives the translation its own independent layout. You can let it diverge from the source — a different hero, an extra section for a local promotion — or bring it back in line with the source when you want them to match.

<Note>
  Translations follow the same promise as everything else: the assistant proposes and previews, and the page goes live only when **you** click **Publish**.
</Note>

## Each language publishes on its own

Every language keeps its own draft. Publishing the German page puts only the German changes live — an English draft you're still working on stays a draft until you publish it in English.

## Translate a block

Reusable blocks translate the same way. Open the block, pick a language from the language menu, and translate its words. A block translation always keeps the source block's layout, and every page that uses the block shows it in the visitor's language.

## Switching languages on the live site

Once your site has more than one language, a **language switcher** appears in the site header — visitors tap a language code (e.g. `EN` / `DE`) to move between languages, landing on the same page in the language they choose. On a single-language site the switcher stays hidden; it lights up automatically the moment you add a second language.

<Tip>
  Start with **symmetric** translation when you just need the same page in another language — it's the least work. Reach for **asymmetric** only when a language really needs its own layout.
</Tip>
